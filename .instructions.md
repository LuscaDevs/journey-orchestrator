# Journey Orchestrator - Copilot Configuration

## Overview
Este projeto usa **Spec Kit** para gestão de especificações com workflows estruturados no Copilot Chat. Todos os workflows estão definidos em `.windsurf/workflows/` e templates em `.specify/templates/`.

## Workflows Disponíveis

### Análise e Planejamento
- **speckit.clarify**: Clarificar requisitos e domínio
- **speckit.specify**: Criar especificações estruturadas
- **speckit.plan**: Planejar implementação com tasks
- **speckit.analyze**: Analisar código e arquitetura existente
- **speckit.constitution**: Revisar/atualizar constituição do projeto

### Execução e Rastreamento
- **speckit.implement**: Implementar features com checklist
- **speckit.checklist**: Gerenciar checklists de tarefas
- **speckit.tasks**: Converter especificações em tasks
- **speckit.taskstoissues**: Converter tasks em issues

## Projeto

### Estrutura de Especificações
As especificações estão organizadas em `/specs/` com numeração sequencial:
- Cada spec tem diretórios: `checklists/`, `contracts/`, `data-model.md`, `plan.md`, `spec.md`, `tasks.md`
- Documentação central em `/docs/`
- Testes em `/test/` e contratos em `/contract-tests/`

### Stack Técnico
- **Backend**: Java 21, Spring Boot 4.0.3, MongoDB
- **Frontend**: TypeScript, React, Vite
- **API**: OpenAPI 3.0.3 (`api-spec/openapi.yaml`)
- **Testing**: JUnit 5, RestAssured, Testcontainers

### Princípios Arquiteturais
- Specification-Driven Development (Spec First)
- Clean Architecture (Hexagonal)
- Domain-Driven Design (DDD)
- SOLID Principles

## Como Usar

### Criar uma Nova Especificação
1. Use `/speckit.clarify` para entender os requisitos
2. Use `/speckit.specify` para criar a especificação estruturada
3. Coloque em `/specs/NXX-feature-name/`

### Implementar uma Feature
1. Use `/speckit.plan` para decompor em tasks
2. Use `/speckit.implement` com checklist durante desenvolvimento
3. Use `/speckit.tasks` para rastrear progresso

### Revisar Arquitetura
1. Use `/speckit.analyze` para análise profunda
2. Use `/speckit.constitution` para validar conformidade

## Templates Disponíveis

Localização: `.specify/templates/`
- `spec-template.md`: Estrutura de especificações
- `plan-template.md`: Planejamento de features
- `checklist-template.md`: Checklists de tarefas
- `tasks-template.md`: Decomposição de tasks
- `constitution-template.md`: Constituição do projeto
- `agent-file-template.md`: Documentação de agentes

## Configuração Spec Kit

Arquivo: `.specify/init-options.json`
```json
{
  "ai": "windsurf",
  "ai_skills": false,
  "branch_numbering": "sequential",
  "here": true,
  "speckit_version": "0.3.2"
}
```

---

**Para usar os workflows no Copilot Chat, digite `/` seguido do nome do workflow, ex: `/speckit.plan`**
